# Face Magic — Cinderella Tab

גרסה זו מבוססת על הקבצים שהועלו על ידך, ובתוכה נוסף טאב חדש של סינדרלה.

## מה חדש
- טאב חדש: סינדרלה
- קעקועי פנים: נעל זכוכית, שמלה כחולה, פיה, נסיך, שעון, כרכרה, כוכבי קסם
- דמויות מהאגדה: פיה, נסיך, חברים קטנים, שעון, כרכרה
- אביזר מלכותי: כתר זכוכית, סרט כחול, ניצוצות, קשת לשיער
- רקעים: אולם נשף, מדרגות הטירה, כרכרה בלילה, גן קסום, חלון וכוכבים

## פרסום
החליפי את ארבעת הקבצים בתיקיית המשחק ב-GitHub Pages.

## הערה
זיהוי הפנים עדיין נטען מהאינטרנט דרך MediaPipe, כמו בקבצים המקוריים.
