# קסם על הפנים 🦋

משחק פילטרים לילדים בעברית: קעקוע, אביזרי פנים ואפקטים בזמן חיוך, עם כפתור **📸 שמור תמונה**.

## פרסום ב-GitHub Pages

1. צרי repository ציבורי חדש ב-GitHub, למשל `face-magic`.
2. העלי **את הקבצים מתוך התיקייה** `face-magic` (לא את קובץ ה-ZIP עצמו): `index.html`, `style.css`, `app.js`.
3. ב-repository בחרי **Settings → Pages**.
4. תחת **Build and deployment** בחרי **Deploy from a branch**, ואז `main` ו-`/(root)` ולחצי **Save**.
5. כתובת המשחק תהיה בדרך כלל `https://USERNAME.github.io/face-magic/` (החליפי USERNAME בשם המשתמש שלך).
6. פתחי את האתר ב-Chrome או Safari בטלפון, לחצי **הפעילי מצלמה**, ואשרי הרשאה.

## שמירת תמונה

הכפתור **📸 שמור תמונה** מוריד קובץ PNG עם הצילום והאפקטים. במכשירים מסוימים (בפרט Safari במכשירי iPhone) התמונה עשויה להיפתח לצפייה, ואז יש לבחור **שיתוף → שמור תמונה**, או להימצא ב-Files/Downloads. התמונות אינן מועלות לשרת.

## פרטיות ובטיחות

- עיבוד זיהוי הפנים והציור מתבצע **בדפדפן** בלבד; אין שרת backend, אנליטיקה או שמירת תמונות בענן.
- קוד MediaPipe ומודל זיהוי הפנים נטענים מ-CDN של jsDelivr ו-Google עם החיבור הראשון. ייתכנו פניות רשת לקבלת קבצים, אך האפליקציה אינה שולחת את תמונות המצלמה.
- המצלמה דורשת HTTPS והרשאה מפורשת. השימוש מיועד בהשגחת הורה; אין לפרסם תמונות של ילדים ללא רשות.
- ברוב המכשירים נדרש אינטרנט להפעלת המשחק; אין הבטחה לפעולה לא-מקוונת.
- לעיתים חומרה ישנה איטית יותר; הקוד נופל בחזרה מ-GPU ל-CPU.

## בדיקות מומלצות

- פתיחה ב-Chrome באנדרואיד וב-Safari באייפון.
- זיהוי פנים בתאורה טובה, הטיית הראש וחיוך.
- בדיקה שהתמונה הנשמרת כוללת את הפילטרים ואינה רק המצלמה.
- בדיקת הרשאות מצלמה, הורדה, מצלמה קדמית ואחורית.

## מבנה

- `index.html` — ממשק עברי
- `style.css` — עיצוב מותאם לנייד
- `app.js` — מצלמה, MediaPipe, ציור ושמירת PNG

אין צורך ב-Node, npm או שרת.


## אם המצלמה לא פועלת
פתחו את כתובת HTTPS של GitHub Pages ולא את `index.html` כקובץ מקומי.
ודאו הרשאת מצלמה בהגדרות האתר, ושאין אפליקציה אחרת שמשתמשת במצלמה.
בגרסה המתוקנת המצלמה נפתחת לפני הורדת מודל זיהוי הפנים. אם המודל לא נטען, הצילום ושמירת התמונה עדיין עובדים, אך הקעקועים לא יופיעו עד שהמודל ייטען.
