# קסם חנוכה – Hanukkah Face Magic

משחק מצלמה משפחתי בעברית עם **וידאו על כל המסך**, קעקועים, כובעים/כתרים, שפמים מיוחדים ואפקטים חיים. כל אפשרות מוצמדת לכל הפנים ש־MediaPipe מצליח לזהות בפריים (עד 8, תלוי במכשיר ובתנאים). התמונה נשמרת מקומית כ־PNG או נשלחת באמצעות תפריט השיתוף של הטלפון.

## פרסום ב־GitHub Pages

1. צרו תיקייה בשם `hanukkah-magic` במאגר GitHub Pages (אפשר גם במאגר `GAMES`).
2. העלו לתוכה את **index.html, style.css, app.js ואת תיקיית assets בשלמותה**.
3. ודאו ש־GitHub Pages פעיל במאגר ופתחו את `https://YOUR_USERNAME.github.io/GAMES/hanukkah-magic/` (שנו שם משתמש/מאגר אם צריך).
4. אשרו הרשאת מצלמה. רצוי לפתוח בדפדפן Chrome או Safari ולא בדפדפן הפנימי של WhatsApp.

## שימוש

בחרו קעקוע, כובע/כתר, שפם או אפקט. הקעקועים חלים על שתי הלחיים כברירת מחדל. אפשר לשנות גודל, לבטל לחי אחת ולצלם/לשתף. "חנוכה שמח" מופיע בווידאו ובתמונה השמורה.

## חשוב לדעת

- אין הרשמה, אנליטיקות, או העלאת צילום לשרת. הזיהוי מתבצע בדפדפן.
- לזיהוי הפנים נדרש אינטרנט לטעינת ספריית MediaPipe וקובץ המודל מאתר חיצוני.
- לא כל המכשירים מסוגלים לעקוב אחרי 8 פנים בו־זמנית; הביצועים תלויים במצלמה, בתאורה ובחומרה.
- GitHub Pages הוא HTTPS, שנדרש להרשאות המצלמה.
- הקוד נבדק תחבירית, אבל נדרשת בדיקת מצלמה פיזית לאחר הפרסום.


## חידוש בגרסה זו
- נוספו קעקועים וכתרים בסגנון קשת בענן, נסיכות ופיות חנוכה.
- נוספו: כתר נסיכת חנוכה, קשת פיית חנוכה, כובע קשת קסום, קשת נסיכות וסביבונים.
- נוספו: חנוכיית קשת, טירת נסיכת חנוכה, יונה ונר קשת, ושרביט וסביבון קסומים.


## תיקון הזיהוי: לפי face-magic.zip שסיפקת
- העברנו את אותו מנגנון טעינה בדיוק: MediaPipe 0.10.22 מ־jsDelivr, אחר כך 0.10.22 מ־unpkg, ואז 0.10.21 מ־jsDelivr; GPU ואז CPU.
- במשחק חנוכה נשמרה תמיכה בעד 8 פנים (במשחק ששלחת הזיהוי הוגדר ל־2).
- לא נדרשת תוספת Workflow, ולא נדרשים קובצי vendor. פרסום רגיל של GitHub Pages מספיק, אבל הזיהוי עדיין תלוי בנגישות ל־CDN ולמודל החיצוניים.
- אם נכשלו כל שלוש הטעינות, המשחק יציג פירוט שגיאה ולא יראה קעקועים עד שהזיהוי ייטען.


## פריסה חדשה (גרסה 5)
התפריט נמצא בראש הדף מחוץ לווידאו, ואזור המצלמה מופיע מתחתיו ותופס את כל המקום שנותר. הכפתור "צמצום" מסתיר את שורת האפקטים והגודל ומשאיר את כפתורי השמירה והשיתוף גלויים. התיקון לא משנה את מנגנון MediaPipe שעובד בגרסה 4. הצילום כולל את הווידאו והאפקטים, ללא כפתורי ממשק.
