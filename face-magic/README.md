# Face Magic — Version 3

אתר משחק קעקועים לפנים ב־GitHub Pages.

1. חלצי את ה־ZIP והעלי את index.html, app.js, style.css, README.md לתיקייה של המשחק (לא את ה־ZIP עצמו).
2. גלשי לכתובת HTTPS של GitHub Pages.
3. רענני רענון מלא. ודאי שמופיע ״גרסה 3 · תיקון זיהוי פנים״.
4. לחצי על ״הפעילי מצלמה״. אם אין זיהוי פנים, לחצי ״נסי שוב״ והעתיקי את פרטי התקלה.

המצלמה והתמונות פועלות בדפדפן ללא העלאת תמונות. לצורך זיהוי הפנים נטענים קובצי JavaScript, WebAssembly ומודל מאתרים חיצוניים.

**הערה:** לא ניתן לאמת כאן הפעלה בדפדפן פיזי. בדיקת תחביר JavaScript נעשית מקומית.
