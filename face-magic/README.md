# Face Magic – Cinderella Wings (Version 7)

מבוסס על הגרסה האחרונה.

- הסרנו לחלוטין את אפשרות השמלה מהקוד, הממשק וקובצי התמונה.
- הגדלנו קעקועים של סינדרלה מכ־35% לרוחב כ־51% מרוחב הפנים.
- הוספנו 3 כנפיים קסומות עם שקיפות: קריסטל, פיה סגולה, זהב.
- נשארו כתר, קעקועים, פיה, נסיך וכרכרה.
- שמירת תמונות כוללת את האפקטים.

## התקנה

חלצי את ה־ZIP והעלי את index.html, style.css, app.js, README.md ותיקיית assets שלמה לתיקיית המשחק ב־GitHub.

אין צורך בשרת. MediaPipe עדיין נטען ברשת, כמו בגרסת הבסיס.

מיקום הכנפיים מחושב לפי נקודות הפנים ולא לפי זיהוי גוף או הפרדת רקע, ולכן עשוי להיות לא מדויק בצילום קרוב מאוד.
