# קסם על הפנים – סינדרלה גרסה 6

גרסה זו נשענת על הקבצים המקוריים שלך ועל טאב סינדרלה.

בטאב סינדרלה יש קבצי PNG שקופים אמיתיים בתיקיית `assets`:
- כתר משובץ באבני ספיר
- חלק עליון של שמלה כחולה עם שרוולים נפוחים
- קעקועי נצנצים, טירה, נעל זכוכית ונעל משולבת בנצנצים
- פיה, נסיך וכרכרה כתוספות בצד התמונה

אין שיער מלאכותי ואין רקעים. כפתור שמירת התמונה שומר את התוצאה עם האפקטים.

## פרסום GitHub Pages
העלי את `index.html`, `style.css`, `app.js`, `README.md` ואת **כל תיקיית `assets/`** לאותה תיקיית משחק ב-GitHub. הקפידי לשמור על שמות ותיקיות.

הכתר והקעקועים מתמקמים לפי נקודות פנים ב-MediaPipe. השמלה ממוקמת בקירוב לפי הסנטר ורוחב הפנים, כי מודל Face Landmarker אינו מזהה כתפיים. בתמונות מסוימות נדרש כיוון נוסף למיקום שלה.

המודל עצמו נטען מהאינטרנט כפי שעשה בפרויקט המקורי. לא בוצעה בדיקת מצלמה פיזית במכשיר.
