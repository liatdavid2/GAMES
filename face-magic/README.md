# Face Magic – בנות ים דלוקס

גרסה זו מבוססת על ארבעת הקבצים שסיפקת, ועל הרחבת בנות הים.

שינויים: שיער רב-שכבתי עם קווצות וגלים, כתרים מצוירים עם צדפים ופנינים, קטגוריית קעקועים חדשה ללחיים (צדפים, כוכבי ים, פנינים, אלמוגים וגלים). הבחירות משפיעות על הציור בזמן אמת ועל קובץ ה-PNG הנשמר.

המצלמה, MediaPipe ומנגנון הצילום המקוריים נשארו כפי שהיו.

להעלאה ל-GitHub Pages: העלי את `index.html`, `app.js`, `style.css`, `README.md` לתיקיית המשחק הקיימת. אין צורך בפעולת build. נדרשים HTTPS, הרשאת מצלמה וחיבור אינטרנט לטעינת MediaPipe המקורי.

בדיקות: תחביר JavaScript וקיום רכיבי UI. לא בוצעה בדיקת מעקב פנים במצלמה פיזית.
