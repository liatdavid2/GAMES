## פרסום ל־GitHub Pages

1. חלצי את ה־ZIP. העלי את ארבעת הקבצים `index.html`, `style.css`, `app.js`, `README.md` אל תיקיית המשחק במאגר שלך (למשל `GAMES/face-magic/`).
2. אל תעלי את ה־ZIP עצמו במקום הקבצים, ואל תחליפי קבצים של משחקים אחרים.
3. פתחי את כתובת HTTPS של GitHub Pages ורענני את הדף (במחשב Ctrl+Shift+R).
4. לחצי על **הפעילי מצלמה** ואז על **🧜‍♀️ עולם בנות הים**.
5. בחרי מראה מוכן או התאימי כל קטגוריה בנפרד. לחצי **📸 שמור תמונה** כדי לשמור קובץ למכשיר.
